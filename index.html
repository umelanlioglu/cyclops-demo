Cyclops Field Assistant

An AI-powered wearable service assistant that combines real-time printer-component segmentation, speech transcription, retrieval-augmented generation, and scene-aware visual guidance.

View Source Code View Demo

Project Demo

The system was demonstrated on a Creality CR-10 Smart 3D printer as a representative industrial service target. The assistant detects visible printer components, understands spoken technician questions, retrieves task-specific knowledge, and returns grounded visual guidance.

Scenario 1 — Real-Time Printer Component Segmentation

This demo shows the computer vision module running YOLO26 Small instance segmentation on a live Creality CR-10 Smart printer video. The system detects and segments visible printer components, forming the visual grounding layer used by the assistant.

What We Built

Real-Time Segmentation

Fine-tuned YOLO26 Small instance segmentation detects and masks 22 Creality CR-10 Smart printer components from the live camera view.

Speech-to-Text Interaction

Faster-Whisper transcribes technician voice queries, enabling hands-free interaction during installation, service, and troubleshooting tasks.

Scene-Aware RAG

The RAG pipeline retrieves relevant information from manuals, tutorial-video transcripts, and curated forum discussions, then grounds the answer in the current visual scene.

Visual Guidance

The assistant highlights relevant detected components using segmentation masks, arrows, and short action captions generated from the selected task context.

Live Worker Pipeline

A file-bridge live worker connects incoming headset camera/audio data with segmentation, transcription, retrieval, generation, and annotated response output.

Wearable Deployment

The system is designed for the Augmency Cyclops HMD Pro-G headset, with Android-side visual feedback and native text-to-speech output.

System Architecture

The headset acts as a thin client while computationally heavy AI inference is offloaded to a KUACC GPU node.

Camera frame + voice query ↓ Cyclops Android application ↓ FastAPI / WebSocket bridge ↓ YOLO26 segmentation + Faster-Whisper transcription ↓ Scene-aware RAG with Gemini ↓ Annotated frame + grounded answer ↓ Visual guidance and spoken feedback on the headset

Tech Stack

  • Wearable Client: Android, Kotlin, Jetpack Compose
  • Computer Vision: YOLO26 Small Segmentation
  • Speech: Faster-Whisper multilingual STT
  • Reasoning: RAG + Gemini generation
  • Backend: FastAPI, WebSocket, file-bridge worker
  • Infrastructure: KUACC HPC GPU node
  • Target Device: Creality CR-10 Smart 3D printer
  • Wearable Hardware: Augmency Cyclops HMD Pro-G
